# Screenshot Evidence

This folder is organized by investigation stage:

- `01-lab-environment/` — agent and environment overview
- `02-network-recon/` — network reconnaissance and firewall/correlation evidence
- `03-windows-sysmon/` — Windows Sysmon process and event evidence
- `04-ssh-authentication/` — SSH/PAM authentication timeline and alert details
- `05-linux-auditd/` — Linux Auditd command execution evidence

The selected evidence set is intentionally small so the repository remains easy to review.

See [`docs/screenshot-evidence-map.md`](../docs/screenshot-evidence-map.md) for the mapping from original screenshot numbers to final repository filenames.
